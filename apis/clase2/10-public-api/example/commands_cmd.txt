REM Exercise 10: Public API Consumption Testing Commands (Windows CMD)

REM ============================================================================
REM AUTHENTICATION TESTS (given here; explained in Exercise 11)
REM ============================================================================

REM 1. Register a new user
curl -X POST -H "Content-Type: application/json" -d "{\"username\":\"alice\",\"password\":\"secret123\"}" http://127.0.0.1:8000/register

REM 2. Login to get JWT token
curl -X POST -H "Content-Type: application/json" -d "{\"username\":\"alice\",\"password\":\"secret123\"}" http://127.0.0.1:8000/login

REM 3. Access profile with JWT token (replace YOUR_TOKEN)
curl -X GET -H "Authorization: Bearer YOUR_TOKEN" http://127.0.0.1:8000/profile

REM ============================================================================
REM WEATHER API TESTS (PUBLIC - No Authentication Required)
REM ============================================================================

REM 4. Get weather for Madrid
curl http://127.0.0.1:8000/weather?city=Madrid

REM 5. Get weather for a specific city
curl http://127.0.0.1:8000/weather?city=Paris

REM 6. Get weather with country code for disambiguation
curl http://127.0.0.1:8000/weather?city=Paris^&country=FR

REM 7. Get weather for London, UK
curl http://127.0.0.1:8000/weather?city=London^&country=GB

REM 8. Get weather for New York, USA (spaces: let curl URL-encode the value)
curl -G "http://127.0.0.1:8000/weather" --data-urlencode "city=New York" --data-urlencode "country=US"

REM 9. Get weather for Tokyo, Japan
curl http://127.0.0.1:8000/weather?city=Tokyo^&country=JP

REM 10. Test with invalid city (should return 404)
curl http://127.0.0.1:8000/weather?city=InvalidCityXYZ123

REM 11. Test without city (should return 422: city is required)
curl http://127.0.0.1:8000/weather

REM ============================================================================
REM NOTES
REM ============================================================================

REM Note 1: Use ^ to escape & in Windows CMD
REM Note 2: A literal space is not valid in a URL: use --data-urlencode (example 8) or %20.
REM         (Avoid %20 inside .bat files: there %2 is replaced by the 2nd batch argument.)
REM Note 3: Weather endpoint is PUBLIC - no JWT token required
REM Note 4: Put your OpenWeatherMap key in .env first (copy .env.example .env), then restart the app
REM         (without it /weather answers 503)
